# A Geometry-Aware Grasping Framework with SkelGG-CNN

This repository contains the open-sourced implementation of the code from the paper:

**"A Geometry-Aware Grasping Framework with SkelGG-CNN: End-to-End Auto-Labeling and Learning via Straight Skeletons."**

> **Note:** The full code implementation will be released soon. Stay tuned for updates!

## Overview

This repository provides the full pipeline described in the paper. It includes:
- Scripts for automatic data collection
- Python Implementation of skeleton-based grasp keypoint annotation algorithm
- The complete code for training and evaluation
